Date: 2026-11-12

The repository owner explicitly directed the workspace to acquire the broader, previously discussed project portfolio instead of stopping at the first ten priority projects. The owner authorized collecting these projects privately first and navigating product-level licensing decisions afterward.

## Authorized purpose

Private internal architecture study, comparative evaluation, inspiration, and reference. This authorization does not certify any candidate for commercial reuse, product incorporation, network deployment, publication, or redistribution.

## Acquisition behavior

1. **Private source mirror:** If GitHub reports a recognized open-source license, create an independent private mirror including source history and writable refs. This includes copyleft licenses such as GPL, LGPL, and AGPL. Their obligations remain applicable to any later distribution or network deployment.
2. **Reference-only record:** If license metadata is missing, unknown, source-available, or not in the recognized open-source allowlist, create a private repository containing the upstream URL, exact pinned commit, default branch, and reported license metadata. Do not copy upstream source files, assets, binaries, or Git history into that repository.
3. **Skipped:** Archived, disabled, unavailable, or unresolvable repositories are reported as skipped. Do not silently substitute a different upstream.

All destinations must remain private and independent (not GitHub forks). Preserve upstream LICENSE, NOTICE, copyright, attribution, and provenance files.

## Later-use gate

Before any source, component, or asset is incorporated into a ULTRST product, deployed as a service, published, or distributed, review root and nested licenses, transitive dependencies, fonts, icons, images, models, datasets, plugins, extensions, enterprise modules, trademarks, attribution, patent terms, and reciprocal-license source/network obligations.

A private copy does not itself grant permission for commercial reuse. This record authorizes private study references only and does not override upstream license terms.
