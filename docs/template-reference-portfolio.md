# Private Template and Reference Portfolio

Snapshot date: 2026-11-12

This is the expanded reconstruction of the projects and categories discussed previously. It adds **208 candidate upstream projects** beyond the eight repositories already verified. Refine remains a separate large-transfer retry.

## Acquisition modes

- Recognized open-source licenses are mirrored into independent private repositories. This includes GPL, LGPL, and AGPL projects; their reciprocal, source-offer, network-use, attribution, and notice obligations remain applicable.
- Missing, unknown, source-available, and unrecognized license metadata produces a private reference-only record with an exact source URL and commit; no upstream code/assets are copied.
- Archived, disabled, invalid, or unresolvable projects are recorded as skipped, not silently substituted.
- All destinations remain private and independent, not GitHub forks.
